# Requirements Placeholder

This directory is reserved for requirements agreed by FIT5120 Team20 and project stakeholders.

The current bootstrap scope is limited to:

- a buildable React, TypeScript, and Vite frontend;
- a runnable FastAPI backend;
- a health endpoint and local connectivity indicator;
- lightweight architecture and project documentation.

Epic 1 and Epic 2 functionality is intentionally excluded. Authentication is not currently in scope for Iteration 1 unless later requirements state otherwise. Future requirements must be recorded here without inferring product or data behaviour that has not been approved.
